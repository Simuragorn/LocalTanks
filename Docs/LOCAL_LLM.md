# Локальная LLM для LocalTanks

## Принятое окружение

- Runtime: standalone Ollama `v0.40.2` для Windows x64.
- Модель первого вертикального среза: `qwen3:8b` (`Q4_K_M`, около 5,2 ГБ).
- API доступен только локально: `http://127.0.0.1:11434`.
- Бинарники: `LocalData/Ollama`.
- Модели: `LocalData/OllamaModels`.
- Оба каталога исключены из Git.

RTX 5060 с 8 ГБ VRAM позволяет разместить выбранную модель на GPU, оставляя небольшой запас. Qwen3 выбран за многоязычность, структурированные инструкции и ролевой диалог. Конкретная модель остаётся настройкой и не зашивается в игровую логику.

## Жизненный цикл

Обычное Windows-приложение Ollama не устанавливается и не добавляется в автозапуск. Игра использует standalone CLI:

1. При запуске Play Mode или игры проверяется существующий локальный API.
2. Если сервер уже работает, игра использует его и не получает право завершать чужой процесс.
3. Перед переходом в готовое состояние проверяется наличие настроенной модели через `/api/show`.
4. Если сервер недоступен, `LocalLlmRuntime` запускает `LocalData/Ollama/ollama.exe serve` в скрытом режиме.
5. Процесс получает локальный каталог моделей и не слушает внешний сетевой интерфейс.
6. При завершении Play Mode или игры останавливается только процесс, созданный `LocalLlmRuntime`.
7. Batchmode и автоматические тесты реальный процесс не запускают.
8. Ошибка запуска, тайм-аут, отсутствие файлов или модели не останавливают бой: используется детерминированный fallback.

Настройки находятся в `Assets/Game/Resources/LocalLlmSettings.json`. Производные бинарники и модели не являются частью репозитория.

Повторная установка выполняется `Tools/LocalLLM/Install-LocalLlm.ps1`. Скрипт скачивает закреплённый официальный релиз, проверяет SHA-256, распаковывает runtime, временно запускает сервер для загрузки модели и обязательно останавливает его. Автозапуск Windows он не изменяет.

## Интеграционный контракт

Игровые системы работают через `ILocalLlmProvider`. Реальный `OllamaLlmProvider` отправляет асинхронный `/api/chat` запрос, отключает длинное внутреннее рассуждение и требует ответ по переданной JSON-схеме. `FakeLocalLlmProvider` используется в тестах и воспроизведении сохранённых решений.

LLM никогда не вызывается из покадрового управления и не блокирует основной поток Unity.
