# LocalTanks

Одиночная 2D-игра о командных танковых боях с видом сверху. Проект разрабатывается в Unity при совместной работе человека и ИИ.

## Запуск текущего прототипа

1. Откройте проект в Unity 6000.6.4f1.
2. Откройте `Assets/Game/Scenes/Battle_TestRange.unity`.
3. Нажмите Play.
4. Управление: W/S — вперёд и назад, A/D — поворот корпуса, мышь — башня, левая кнопка — выстрел; удерживайте её для последовательного огня.
5. Колесо мыши приближает и отдаляет камеру. Клавиша P или кнопка HUD останавливает и возобновляет вращение машин полигона.

Боевые параметры находятся в JSON под `Assets/Game/GameData/Definitions`. После их изменения импорт выполняется автоматически; его также можно запустить через `Local Tanks > Data > Reimport Combat Definitions`.

Если префабы, сгенерированные данные или сцена были удалены, выберите `Local Tanks > Build Sprint 002 Prototype`.

## Навигационный полигон

1. При необходимости выберите `Local Tanks > Build Navigation Range`.
2. Откройте `Assets/Game/Scenes/Battle_NavigationRange.unity` и нажмите Play.
3. Игрок управляется как на боевом полигоне; выстрелами можно разрушить коричневую стену в центре.
4. Три стендовые машины самостоятельно патрулируют карту, учитывая дороги, грунт, грязь, воду и препятствия.
5. Клавиша F2 включает и отключает диагностическую сетку и маршруты; колесо мыши меняет масштаб.

Редактируемый источник карты: `Assets/Game/GameData/Maps/navigation_range.json`. Сцена и Tilemap пересоздаются Editor-инструментом, поэтому их UnityYAML вручную менять не нужно.

## Карта «Переправа»

1. При необходимости выберите `Local Tanks > Build River Crossing Map`.
2. Откройте `Assets/Game/Scenes/Battle_RiverCrossing.unity` и нажмите Play.
3. На карте есть две базы, три переправы, лесной север, застроенный центр, открытый юг и поперечные дороги между направлениями.
4. На своих базах появляются две команды по 7 машин. Игрок управляет одним Tiger II Team A, остальные 13 машин расходятся по трём направлениям и ведут бой самостоятельно.
5. F2 показывает навигационную сетку, F3 — диагностику обзора, F4 — состояние ближайшего боевого ИИ, F5 переключает скорость времени ×1/×3; колесо мыши меняет масштаб.

Редактируемые источники: карта `Assets/Game/GameData/Maps/river_crossing.json` и состав боя `Assets/Game/GameData/Scenarios/river_crossing_battle.json`. Художественный набор находится в `Assets/Game/Art/Environment/RiverCrossing`; игровая проходимость от него не зависит.

Главный план: `PROJECT_PLAN.md`. Текущее состояние: `Docs/STATUS.md`.
