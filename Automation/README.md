# Автоматизация проекта

`Automation` — единый репозиторный корень всей повторяемой автоматизации LocalTanks, предназначенной для ИИ-агентов и контентных конвейеров.

```text
Automation/
├── skills/       инструкции и вспомогательные проверки для агентов
└── pipelines/    воспроизводимые конвейеры техники, карт, окружения и звука
```

Обе папки коммитятся и отправляются вместе с проектом. Отдельных актуальных копий этих скиллов или конвейеров вне репозитория нет.

## Порядок работы для нового ИИ

1. Прочитать `AGENTS.md`, `Docs/README.md`, этот файл и короткий `Docs/STATUS.md`.
2. Найти подходящий скилл в `Automation/skills/` и прочитать его `SKILL.md` полностью. Имя каталога совпадает с именем скилла.
3. Выполнять процедуру через `Automation/pipelines/`, на который ссылается скилл. README и скрипты конвейера определяют реальные параметры запуска.
4. Не читать и не обновлять как источник истины одноимённые скиллы в пользовательских каталогах Codex, DeepSeek или других агентов. Память чата и исторические документы также не заменяют текущий `SKILL.md`.
5. Изменение процедуры считается завершённым только вместе с обновлением её скилла, конвейера, документации, проверок, коммита и push.

Если подходящего скилла нет, новый проектный скилл создаётся в `Automation/skills/`, а повторяемая исполняемая часть — в `Automation/pipelines/`. Нельзя создавать вторую актуальную копию вне этого корня.

Локальные зависимости и производные материалы не коммитятся: конфигурация установки WoT, Blender add-on, рабочие кэши, извлечённые модели, текстуры и звук остаются в исключённых `Local`, `ThirdParty`, `LocalData` и `Assets/LocalOnly`. После клонирования они воспроизводятся setup/invoke-скриптами соответствующего конвейера.

Общие инструменты, не являющиеся контентными конвейерами, остаются в `Tools/`: фоновый запуск Unity, локальная LLM и проверка документации.

Карта скиллов и конвейеров находится в [`Docs/README.md`](../Docs/README.md). Структура и связи проверяются командой:

```powershell
& .\Tools\Docs\Test-ProjectDocumentation.ps1
```
